# TabShare

Go 中继服务 + Chrome Manifest V3 扩展。共享本机的一个真实标签页，访客直接打开链接即可共同操作，使用同一标签页的页面状态和登录状态。

普通页面在访客浏览器中直接渲染 DOM，文字可选择、复制，表单使用浏览器原生控件。首次发送页面结构，之后只同步变化的节点、属性、文字和表单状态。Canvas、跨域 iframe、视频等区域采用有限帧率的画面降级；发现覆盖关系或区域超出视口时，临时采用整页画面。没有音频、麦克风、录制功能。

## 本机启动

需要 Go 1.26+。Node 22+ 和 Chromium 仅用于测试。

```sh
go mod download
go build -o bin/tabshare ./cmd/tabshare
./bin/tabshare -listen 127.0.0.1:8080 -public-url http://localhost:8080 -data .data
```

首次启动在 `.data/admin-token` 中生成配对令牌。只在你自己的机器上读取该文件并填入扩展设置；不要把令牌放进分享链接。`.data/sessions.json` 保存分享标识和密钥，需保留数据目录以维持已有链接。

在 Chrome 的扩展管理页面开启开发者模式，选择“加载已解压的扩展程序”，加载本仓库的 `extension` 目录。打开 TabShare 设置，填写服务器地址和配对令牌，允许访问该服务器，勾选自动连接。

共享会话有访客连接时，源网页右下角出现 **TS 共享设置** 悬浮按钮。点击可切换 **本地模式（DOM 同步）** 或 **远程模式（画面流）**。访客网页也有同样入口；选择保存在扩展的会话设置中，所有访客同步切换，标签页和登录状态保持。DOM 模式仍会自动为复杂区域使用画面降级；画面模式停止常规 DOM 采集，只保留视口元数据和有限帧率截图。

点击扩展按钮：

- **共享当前标签页**：绑定该标签页；标签页关闭后，不会自动打开替代页。浏览器重启后需要重新分享，防止标签页 ID 被复用。
- **创建可复用的网址分享**：相同浏览器配置和相同网址返回相同分享链接。优先复用该会话原标签页，即使它已经导航到其他页面；原标签页关闭后，下一位访客连接时复用已打开的匹配网址，或新建一个后台标签页。
- **停止并撤销链接**：立即拒绝后续访问；撤销状态在服务重启后仍保留。

网址匹配去掉 fragment，保留路径和 query。不同路径或 query 是不同的网址分享。多个访客共用同一个标签页，输入按服务端接收顺序执行；上限为每个会话 32 名访客。多人同时编辑同一表单时，仍会互相影响，不是独立的账号或独立页面副本。

首次配置和创建分享由浏览器所有者主动完成。之后不逐次询问访客加入，支持自动连接与恢复。Chrome 自己的调试提示保持可见。共享电脑需要开机、Chrome 运行且能连接服务器；Go 服务器没有直接访问本机浏览器的能力。

## 不同屏幕与共享视口

访客设置中的 **我的显示** 独立生效并保存在当前浏览器：

- **适应窗口**：保持比例，完整显示共享视口；随窗口大小、横竖屏、全屏和软键盘可用空间变化更新。
- **适应宽度**：按可用宽度显示，可在访客窗口上下平移查看；**原始尺寸**和 **25%–200% 自定义缩放**可横向、纵向平移。
- **全屏**：扩大页面显示区域，保留退出按钮和悬浮设置；不支持浏览器全屏的设备使用沉浸显示。

本地显示缩放保留源网页的布局，使用 CSS 像素换算点击与滑动位置，DPR / Retina 像素密度单独处理。调整本地窗口或缩放不会要求源端重发全量 DOM 或新增截图。DOM 模式可使用本地原生触控滚动；整页画面模式支持触摸点击、滑动滚动及屏幕键盘输入。

需要真正按访客窗口重新排版时，勾选 **按我的窗口自动调整共享视口**。扩展调整同一个真实标签页的页面视口及像素密度，源网页 CSS 媒体查询和 resize 行为随之生效，所有访客看到同一份响应式布局。一个标签页共用一套真实视口；最近勾选此项的访客驱动尺寸，其他访客停止跟随并继续独立缩放。驱动者横竖屏切换会更新共享视口与屏幕方向；尺寸更新去重并防抖 450ms。源网页登录状态、标签页和会话保持。

取消跟随、点击 **恢复源浏览器视口** 或当前驱动者断开时恢复浏览器原视口；旧驱动者离开不会覆盖新的驱动者。暂停和连接断开也会清理扩展设置的视口覆盖。共享网页打开的弹出页继承当前共享视口。

共享视口的宽度限制为 320–3840 CSS 像素、高度为 240–2160，DPR 限制 1–2，并将截图尺寸控制在每边 4096 像素及约 830 万像素以内。复杂大画面超过中继单帧预算时逐级降低 JPEG 质量；画面流仍受帧率和流量预算约束。原生系统控件、字体绘制和移动浏览器的键盘行为会随设备变化，不能保证所有网站都在不同设备上逐像素一致。

## 公网部署

Go 服务只需要接收来自扩展和访客的 HTTPS/WebSocket 连接，不需要连接到共享电脑的入站端口。

提供 Docker Compose + Caddy 配置，自动重启并保留数据。准备域名，解析到你的服务器，开放 80/443，在仓库根目录运行：

```sh
export TABSHARE_DOMAIN=tabs.example.com
docker compose -f deploy/compose.yaml up -d --build
```

通过服务器上的 Docker 卷安全读取 `/data/admin-token` 并配置扩展。公网扩展地址必须使用 HTTPS。部署文件已提供，云任务没有替你部署公网服务或申请证书。

## Tag 自动构建

推送任意 tag 到 GitHub 时，`.github/workflows/tag-build.yml` 自动运行 Go race 测试、`go vet` 、扩展控制器测试及真实浏览器协议集成测试。通过后构建 Linux、macOS、Windows 的 amd64/arm64 服务端，以及 Chrome 插件 ZIP；产物带 SHA-256 校验文件，在对应 Actions 运行的 Artifacts 中保留 30 天。工作流也支持手动运行。

例如，在准备发布的主分支提交上创建并推送标签：

```sh
git tag v0.3.0
git push origin v0.3.0
```

本地创建标签不会触发 GitHub 构建，必须将标签推送到远端。当前工作流上传构建产物，不自动创建 GitHub Release。

## 差异同步与资源预算

源标签页的隔离脚本用 `MutationObserver` 收集变化。相同节点的多次变化合并，默认最多每 200ms 发送一批。只计算受影响节点的样式，不每批扫描整棵 DOM；class/style 变化需要更新受影响子树。初次连接、导航和明确的重新同步发送完整结构；新访客从服务端已合并的当前状态初始化，不要求源浏览器再次全量发送。

常规 DOM 增量的软预算为每标签页 128 KiB/s。超过预算的批次会延迟下次同步，期间继续合并变化；初始结构不计入此持续预算。画面降级最多 2 帧/s，软预算 64 KiB/s。预算是调度上限，单个批次、首次结构以及 WebSocket/JSON 开销可能产生短时突发。多个不同分享链接绑定同一标签页时，当前实现会分别转发，流量随链接数量增加。

图片、背景图和字体通过源浏览器的资源缓存读取，必要时仅对已加载的 URL 使用源浏览器网络上下文补读，支持跨域和需登录的资源。资源以独立二进制上传，DOM 增量中只携带短资源标识；服务器按 SHA-256 去重，访客验证哈希后生成本地 Blob URL。资源使用独立 256 KiB/s 软预算，单个对象可短时突发；单资源上限 8 MiB、会话最多 256 项 / 32 MiB、服务器全局 128 MiB，源端和访客端也有 32 MiB 资源缓存上限。导航、最后一名访客离开、浏览器断开或撤销时清理服务器资源，资源不会落盘。浏览器无法读取或预算超出时自动整页画面降级。

静止页面不发送 DOM 数据，连接保活每 20 秒一次。CSS 动画使用可读取的 keyframes 在访客端本地播放，不采样每帧动画样式。JavaScript 动画产生的 DOM 变化按批次合并，可能降低动画流畅度。原页面复杂度、资源大小和网络延迟都会影响体验；这不是对所有网站都保持原生表现的保证。

## 安全和兼容性

分享密钥是随机的 256 位 capability，放在 URL 的 `#` 后，不进入 HTTP 请求路径。持有完整链接的任何人都有页面控制权，请仅分享给可信的人。配对令牌只能保存在受信任的扩展和服务器中。服务端只允许固定的页面控制操作，不接受访客传入任意 CDP 命令或 JavaScript。

镜像 iframe 禁止执行原网页脚本、表单提交和外部网络访问。原网站 JavaScript 继续在源标签页执行；镜像只渲染经过白名单处理的元素、样式和状态。登录 Cookie 不会复制到服务器或访客。已填写的密码不传入 DOM 镜像。画面降级会包含所共享视口中的可见内容。服务端保留运行中的 DOM 状态和会话信息；管理员可以看到经中继传送的页面内容，因此需要使用可信服务器。

已适配 `::before` / `::after` / dialog `::backdrop`、可读取的字体和 keyframes、通过 CDP 解析的封闭 Shadow DOM、富文本选区与可信源端输入、单选下拉框的可信键盘提交、多选值、HTML dialog/popover，以及 alert/confirm/prompt/beforeunload 提示。提示由所有访客共同查看，首先提交的有效回答作用于源网页。共享页直接打开的弹出标签页可跟随共享（最多四层），关闭弹出页后返回来源标签页；设置中也可关闭当前弹出页。其他已有标签页不会加入共享。

一比一的实际边界：系统菜单采用访客浏览器原生控件，操作系统、浏览器版本、字体渲染和控件外观仍会有差异。多选与单选键盘路径不适用时使用受限的 DOM 事件提交。富文本的复杂插件、跨框架编辑行为、封闭组件样式变化、CSS 特殊绘制和不可读取资源不能保证完全复现，可用悬浮设置切换整页画面。DOM 有 3500 节点及约 3 MB 采集预算，超过预算会整页画面降级；服务端有 4 MiB 状态上限。只跟随已共享页作为 opener 创建的弹出页，不扫描或加入其他页面；暂停、断线或浏览器重启后的未关闭弹出页不会自动恢复，原主标签页仍按原会话复用。分享没有实现域名锁、P2P、文件传输、浏览器桌面或系统操作。

```sh
go test -race ./...
npm ci --ignore-scripts
npm test
go build -o bin/tabshare ./cmd/tabshare
# 字体资源测试默认使用 Linux DejaVuSans.ttf；可通过 TEST_FONT_PATH 指定 TTF
CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e
```

浏览器集成测试使用真实 Chromium、真实 Chrome DevTools Protocol 和真实访客页面。由于云环境管理员策略禁止加载自定义扩展，测试用 Chrome API 适配器运行原始 `worker.js`，没有修改管理员策略。这验证浏览器控制、页面同步、会话和中继链路，但不代表已验证 Chrome 扩展安装、权限提示或 MV3 生命周期；这些仍需在允许加载扩展的本机 Chrome 中检查。
