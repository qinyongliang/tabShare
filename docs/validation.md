# 云环境验证记录

本仓库最初没有提交和项目文件。本次已建立 Go 服务、MV3 扩展、浏览器 DOM 镜像及部署/开发配置。应用尚未部署到公网。

环境使用 Go 1.27.2（官方下载并验证 SHA-256）、Node 24.19.0、Chromium 154。Go 模块保持 SumDB 校验，npm 使用 lockfile 和包完整性校验。

验证包括：

- Go 单元及 WebSocket 集成检查，使用 race detector：URL 会话复用和持久化、浏览器重启后 tab ID 隔离、两个访客的 DOM/输入转发、认证与撤销、输入白名单、增量合并、后加入访客重建以及错误增量的原子拒绝。
- Node 控制器检查：关闭后网址重新打开、已打开网址复用、指定标签页不重新打开、固定 CDP 操作、HTTPS 要求及 query 保留。
- 真实浏览器协议集成：两名访客、点击、中文/文本输入、粘贴、特殊按键、原生 checkbox/select、滚动、导航、Cookie 保持、登录会话复用、源码标签页关闭后重开、服务器重启自动重连、旧分享密钥撤销。
- DOM 更新：静止页面没有 DOM 消息；编辑仅产生节点/属性差异；CSS keyframes 在访客端播放；JavaScript 连续样式变化合并为不超过每秒 5 批。
- 屏幕适配：390×844 竖屏、390×260 窄窗口、844×390 横屏和 3840×2160 4K 访客窗口完整适配；缩放后的真实 DOM 点击；独立的适应宽度、原始尺寸与自定义缩放；浏览器全屏及全屏不可用时的沉浸显示。
- 共享视口：响应式 CSS 在源网页重新计算并同步给所有访客；驱动者交接、旧驱动者窗口变化不覆盖新驱动者、恢复视口、驱动者断开自动恢复、横竖屏方向与 DPR=2。真实移动访客中的 Retina 整页画面点击与触摸滑动滚动；滑动不会变成点击。
- 几何与预算：低于 10% 的小窗口缩放、平移后的坐标换算、DPR 与 CSS 坐标分离、滚轮单位转换、共享视口及截图像素预算；大截图降 JPEG 质量以满足中继单帧上限。视口输入验证、驱动身份由服务端赋值、旧驱动者断开不清理新驱动者。
- 兼容性：需要源 Cookie 的跨域 SVG 图片、背景图及跨域样式表中的 TTF 字体经资源中继加载；伪元素内容；封闭 Shadow DOM 按钮/输入；跨 strong/em 节点的富文本选区替换及可信源端 input 事件；JavaScript prompt、HTML modal/popover；源端固定悬浮设置、访客模式设置、模式持久化和标签页保持；来源标签页打开弹出页，关闭后返回原页。
- 资源安全：会话密钥隔离、上传所有者认证、HTML MIME 拒绝、资源标识不可变、后加入访客元数据、缓存释放以及新增输入参数校验。
- 降级：Canvas 区域画面及输入；覆盖浮层触发整页画面；移除浮层后返回 DOM，并检查局部截图像素已更新。

一轮动画样例测试在 2.1 秒内发送 5 个差异包，约 2.5 KB。1500 节点页面中的单节点增量合并 microbenchmark 约 2.4 μs/次、953 B 分配/次。这些是当前机器和测试页面的结果，不代表任意网站或并发规模的性能保证；初始结构、图片和画面降级流量另计。

云机器的管理员策略 `ExtensionInstallBlocklist: ["*"]` 禁止加载自定义扩展，实际加载尝试被拒绝。`WebRtcIPHandling: disable_non_proxied_udp` 也禁止直接 UDP 协商。因此浏览器集成用 Chrome API 适配器运行未经改写的 worker 主体，连接真实 CDP。没有修改系统策略。扩展加载、权限提示、MV3 后台存活及用户电脑环境仍需在允许开发者扩展的 Chrome 中验证。Docker/Caddy 公网部署为可选配置，本任务没有执行公网部署或验证证书签发。

## 0.4 WebRTC 验证（历史记录）

Go race / vet、14 项 Node 检查、独立 TURN fixture 构建与 vet、tag 工作流 actionlint 和 Compose 配置解析均通过。分别执行了 `TEST_RTC=0 npm run test:e2e` 和 `TEST_TURN=1 npm run test:e2e`，两套完整浏览器检查均通过。

WebRTC 检查运行真实浏览器中的原始 offscreen 模块及 RTCPeerConnection，使用仅监听回环地址的 Pion TURN/TCP fixture。测试仅把 PeerConnection 的 ICE 策略设置为 relay 以确定性验证 TURN，不修改 Chrome 管理员策略。生产连接继续优先直连。验证了：

- 两名访客通过可靠 DataChannel 操作同一标签页；DOM 差异和输入不经 Go WebSocket 转发。
- 源 Cookie 资源读取后，SVG 图片、背景图和 TTF 字体通过二进制 DataChannel 到达；检查这段期间 Go 资源上传数量没有增加。
- 主动关闭真实 PeerConnection 后，恢复完整兜底 DOM，原标签页仍可操作，并在无所有者操作时自动重新协商 WebRTC。
- 手机视口与 DPR=2、视频触控、横竖屏、多人尺寸驱动、恢复布局；DOM 与视频模式切换、诱导弹出页和返回。
- Canvas 区域视频和点击，重叠浮层切换整页视频，移除后恢复区域。CDP 在真实源页持续绘制 Canvas，访客在 2.1 秒解码 21 帧，超过应急截图每秒 2 帧限制；这是本机测试结果，30 fps 是目标而非保证。
- 自动新建的后台标签页视频初始化。无合成帧时自适应补充截图，重复画面跳过；视频经 WebRTC 编码，JPEG 不通过 Go 转发。
- 视频区域元数据按 DOM 文档版本隔离，导航后不会把旧 Canvas 区域覆盖到新文档的文字或富文本节点。

直接 UDP 穿透、真实公网 TURN/coturn 防火墙、原生 tabCapture 授权及 MV3 offscreen 文档生命周期未在此云策略环境验证。原生 tabCapture 路径提供实现，需所有者在允许安装扩展的本机 Chrome 检查；无人值守重开的网址页采用调试视频来源。Compose 的可选 coturn profile 已校验配置，没有在公网启动。

## 0.4.1 同进程 TURN 验证

用正式 Go 服务内置的 Pion TURN 替代独立测试 fixture 和 Compose coturn profile。HTTP、STUN、TURN UDP/TCP、可选 TLS 运行在同一个进程。默认本地开发不启用 TURN；公网 Compose 默认启用并要求提供服务器 IPv4。临时密钥自动持久化，已认证的分享成员自动获得临时 ICE 凭据，重连时重新签发。

Go race 检查通过，新增检查使用真实 TURN 客户端验证 UDP/TCP/TLS 双向报文与实际分配端口、STUN、错误密码/过期/未知账户拒绝、默认私网权限拒绝、端口和分配限制、启动失败回滚、密钥权限和重启复用、访客离开/撤销后的中继清理，以及服务停止后释放监听器。TLS 检查使用测试 CA 校验证书，未关闭校验。重新协商测试验证两端同时收到新凭据。

真实浏览器检查 `TEST_TURN=1 npm run test:e2e` 已通过：两个访客通过同一个 Go 服务的 TURN/TCP 建立原始 RTCPeerConnection，DOM、输入和图片/字体使用 DataChannel，视频使用 RTP 轨道；主动断开后无需所有者操作即可恢复。导航、共享屏幕尺寸、移动端、多访客、局部视频与整页切换、重启重连和撤销均通过。视频样例在 2.1 秒解码 21 帧。首次浏览器运行曾在原生下拉框处超时，增加失败时的源端/输入诊断后，完整重跑通过，未稳定复现；没有修改或跳过下拉框断言。

Go vet、14 项 Node 检查、tag 工作流 actionlint、Compose 配置解析以及 Linux/macOS/Windows 的 amd64/arm64 六种无 CGO 构建均通过。`TEST_RTC=0 npm run test:e2e` 的完整应急传输回归也通过。已重新执行可复用安装脚本，依赖安装和应用构建成功。

本次仍只验证回环地址的中继。公网 IP、NAT 端口映射、安全组、DNS、证书部署及实际用户电脑的扩展权限未在云环境中配置或验证。
