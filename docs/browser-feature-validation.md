# 本轮浏览器能力补齐与验收清单

这份文件描述开发分支的实现与待验范围，不代表已经发布。基线 v0.7.1。

## 剪贴板

- 中文/emoji 长文本按 UTF-8 和 JSON 报文预算拆分，首块替换选区，后续有序追加。单次 256 KiB，超出明确报错，不能静默截断。
- Ctrl/Cmd+C/V/X 的按下与松开留给本地剪贴板事件；剪切只发送一次删除，避免重复剪切/孤立 keyup。
- 数字输入框等不支持 selectionStart 的控件不调用 setRangeText。
- Clipboard.read 缺失时尝试只读文本 API；没有 API 时提示系统粘贴。
- 目前针对用户复制/粘贴/剪切事件；源站脚本直接调用 clipboard.writeText 的结果代理尚未实现，不应写成全部 Clipboard API 支持。

## 定位

使用访问者位置，明确显示共享网页来源后由访问者点击允许，再触发访客浏览器原生权限。只路由到发起操作的访问者；无法确定时失败关闭。返回坐标直接送给指定源页面回调，不进入 DOM 缓存或广播。网页自身随后渲染的位置内容可能由其他共享访客看到，提示中已说明。

支持主页面 getCurrentPosition/watchPosition/clearWatch。每页最多4个待处理请求，持续定位最多10分钟。导航、取消、超时、访客离开和共享停止均清理。之后主页面导航通过 document-start 脚本拦截早期调用；共享开始前的调用不能追溯替换。Permissions.query 和跨域 iframe 不在本轮完整兼容承诺内。

验证请使用虚构固定坐标，不获取真实人员位置。至少检查：允许/拒绝/超时、watch反复更新/clearWatch、错误访客伪造响应、多个访客、导航迟到结果、关闭共享、源端原生方法恢复。

## 流式下载

取消 64 MiB 单文件上限，保留每块256 KiB、每源标签页2文件、JS安全整数偏移这些资源/协议边界。

GET/POST只消费原始响应，不重复请求；Blob在源页面早期抓取 URL 后使用 BYOB Reader 逐块读取。访客使用 File System Access 写入所选文件。每块确认实际 write 完成才回传 ACK，发送方等待 ACK 再读下一块；磁盘慢时停止往后读取。关闭/错误时 abort，不构造整文件 Blob、不保留 chunks 数组或完成文件的 Blob URL。

没有 File System Access 的浏览器明确提示不支持流式保存；这项兼容性改变需在发布说明中说明。测试中的保存选择器使用 OPFS 测试适配，不代表真实 OS 保存对话框已验证。E2E 仍测试真实数据通道、服务中继与文件流写入。

待验：GET/POST/Blob 三种源各至少一个 >64MiB 文件；校验总大小和内容hash；限速磁盘、取消选择器、中途写入失败、断线、切换传输、重复下载、两文件并发；其他访客不可收到下载数据或 ACK 权限。输入/页面状态在下载等待时仍须可用。

## 0.8.1 样式与加载反馈回归

- Node 单元：资源并行调度与字节准入、同 id 在途去重、导航丢弃旧资源、本地反馈计时、ACK 归属和非法 id。
- Go：input-ack 仅发给指定访客；镜像 CSP 允许样式但禁止脚本，外壳 style-src self 保持不变。
- 浏览器新增 `npm run test:feedback`：严格外壳 CSP + sandbox 镜像中验证带 style 的 SVG 像素；点击后无需等网络、无可见文案的原生 CSS 转动动画；首屏构建完成前隐藏不完整树；3000 个原生 SVG 节点/文字的完整性和几何比较。
- 扩展与服务器需同时更新以获得 input-ack。旧组合可能显示等待反馈，不能把它等同于业务执行失败。
- prepare.js 等扩展尝试在 sandbox iframe 注入脚本时，浏览器可能继续记录 script blocked；不通过 allow-scripts 消除此保护日志。
- dot 当前云端命令沙箱阻止 Chromium 所需的 socket 与 TURN 路由查询；本地 Node 和非 TURN Go 回归可执行，完整浏览器/TURN 验证由仓库 Actions 执行，以最终运行结果为准。
- 部署域名在 dot 云端浏览器和 HTTP 读取中返回 502；尚不能将受控 fixture 通过表述为该部署现场已验证。

- 新增 P2P 分片轮转回归：12 个小资源可在大图片之前完成；超过字节准入预算时等待而不是断开；关闭连接释放待发送/待准入资源。
- 新增小数视口/缩放的 fit 边界测试，浏览器 E2E 保留多尺寸/滚动及输入坐标验收。
