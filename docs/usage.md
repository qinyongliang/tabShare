# 使用指南

[返回 README](../README.md)

## 连接浏览器

服务启动后，在 Chrome 的扩展管理页面开启开发者模式，选择“加载已解压的扩展程序”，加载仓库的 `extension/` 目录，或解压从 Releases 下载的插件 ZIP 后加载。升级时同时更新服务器和扩展，在扩展管理页重新加载扩展，再刷新访客页面。

打开扩展设置，填写服务器地址和配对令牌，勾选 **允许自动连接到我的服务器**，保存并允许访问该服务器。公网地址使用 HTTPS；本机开发可使用 HTTP 回环地址。

配对令牌由服务器首次启动时生成，保存在数据目录的 `admin-token` 文件中。它授予浏览器创建和撤销分享的权限，只应保存在自己的扩展和可信服务器中。

## 创建分享

- **共享当前标签页**：绑定该标签页；标签页关闭后，不会自动打开替代页。浏览器重启后需要重新分享，防止标签页 ID 被复用。
- **创建可复用的网址分享**：相同浏览器配置和相同网址返回相同分享链接。优先复用该会话原标签页，即使它已经导航到其他页面；原标签页关闭后，下一位访客连接时复用已打开的匹配网址，或新建一个后台标签页。
- **停止并撤销链接**：立即拒绝后续访问；撤销状态在服务重启后仍保留。

网址匹配去掉 fragment，保留路径和 query。不同路径或 query 是不同的网址分享。多个访客共用同一个标签页，输入按源浏览器接收顺序执行；上限为每个会话 32 名访客。多人同时编辑同一表单时，仍会互相影响，不是独立的账号或独立页面副本。

首次配置和创建分享由浏览器所有者主动完成。之后访客加入无需逐次确认，扩展支持自动连接与恢复。共享电脑需要开机，Chrome 和扩展需要保持运行并能连接服务器。Chrome 自己的调试提示会保持可见。

## 页面与悬浮设置

共享网页占满访客内容区域，地址输入、连接状态、重连和显示设置都收在 **共享设置** 面板中。源网页和访客页面各有一个可拖拽的 **共享设置** 按钮；拖动不会打开面板，松开后点击才打开，窗口变化时按钮会限制在可见边界内。源端按钮不进入 DOM 镜像。

文字和表单使用 DOM 差异同步，Canvas、嵌入页面等使用可见区域的视频补偿。部分越界会裁剪，重叠区域遮罩处理，始终保留 DOM 页面。两个端点之间优先使用 WebRTC；视频没有音频轨道。

源网址写入分享链接的 hash，保留页面自身的 query 和 fragment。使用浏览器原生前进、后退遍历访问期间的远程历史，包括 SPA 的 pushState、replaceState 和锚点变化。其他访客跟随同一个真实标签页；刷新分享页会继续连接当前页面。设置面板中也可输入完整网址和刷新远程页面。

右键输入框使用访客浏览器的原生菜单。网页自定义右键菜单在源端执行并同步；其他位置提供复制、粘贴、链接和导航菜单。图片粘贴支持 PNG、JPEG、WebP、GIF，单次最多 4 MiB，优先使用 P2P。源端先将图片写入系统剪贴板，再执行原生粘贴，使依赖可信 paste 事件的编辑器能够接收图片；这会替换源电脑当前的剪贴板图片。扩展新增 `clipboardWrite` 权限，Chrome 可能要求重新启用。浏览器拒绝写入时尝试 DOM 粘贴，复杂编辑器不保证接受该降级路径。

局部视频中的输入使用跟随远端光标的本地输入代理，按访客缩放、滚动和 iframe 偏移换算输入法位置。可读取的文字选区同步到访客，支持浏览器原生复制和右键菜单；跨域隔离或自绘编辑器无法读取光标时先按点击位置定位。原网页的自定义右键菜单继续在源端执行。

共享页的 HTTP 附件、带 `download` 的链接和页面生成的 Blob 文件可转发到发起操作的访客，在访客浏览器下载。GET/POST 附件读取实际响应，不重复提交请求；文件以 256 KiB 分块校验，优先 P2P，连接建立前使用服务中继。单文件及访客接收缓存上限 64 MiB，每个源标签页最多同时转发两个文件；完成后“共享设置”保留下载入口，浏览器阻止自动下载时可点击领取。来源是共享页实际响应或页面 Blob，不读取电脑上的其他文件。多人紧接着触发同一页面操作时，下载按源端记录的操作发起者归属。

共享页打开的弹窗会在同一分享中自动跟随，保留输入和下载能力；关闭后回到来源页，不加入其他已有窗口。

## 屏幕适配

访客设置中的 **我的显示** 独立生效并保存在当前浏览器：

- **铺满窗口**（默认）：不留外层空白；比例不同时可平移查看超出窗口的部分。
- **适应窗口**：保持比例，完整显示共享视口；随窗口大小、横竖屏、全屏和软键盘可用空间变化更新。
- **适应宽度**：按可用宽度显示，可在访客窗口上下平移查看；**原始尺寸**和 **25%–200% 自定义缩放**可横向、纵向平移。
- **全屏**：扩大页面显示区域，保留退出按钮和悬浮设置；不支持浏览器全屏的设备使用沉浸显示。

本地显示缩放保留源网页的布局，使用 CSS 像素换算点击与滑动位置，DPR / Retina 像素密度单独处理。调整本地窗口或缩放不会要求源端重发全量 DOM 或新增截图。支持本地原生触控滚动、点击、文本和表单输入。

第一位访客默认驱动共享视口，以匹配其窗口。需要切换驱动者时，勾选 **按我的窗口自动调整共享视口**。扩展调整同一个真实标签页的页面视口及像素密度，源网页 CSS 媒体查询和 resize 行为随之生效，所有访客看到同一份响应式布局。一个标签页共用一套真实视口；最近勾选此项的访客驱动尺寸，其他访客停止跟随并继续独立缩放。驱动者横竖屏切换会更新共享视口与屏幕方向；尺寸更新去重并防抖 450ms。源网页登录状态、标签页和会话保持。

取消跟随、点击 **恢复源浏览器视口** 或当前驱动者断开时恢复浏览器原视口；旧驱动者离开不会覆盖新的驱动者。暂停和连接断开也会清理扩展设置的视口覆盖。共享网页打开的弹出页继承当前共享视口。

尺寸、DPR 和画面预算的具体限制见 [兼容性与限制](compatibility.md)。

## 停止共享

在扩展中选择 **停止并撤销链接**，可以关闭当前分享的访问权。撤销状态在服务重启后仍保留。关闭自动连接可暂停该扩展的远程访问。

完整分享链接包含访问密钥，持有链接的人可以控制页面。请只发给可信的人；需要收回访问权时撤销链接。
